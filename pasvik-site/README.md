# Летописи природы · Пасвик

Веб-интерфейс для `parkit-backend`. Показывает загруженные документы и ход обработки, каталог наблюдений, строгие фильтры, экспорт CSV/Excel и отдельные проверки OCR, LLM и RAG. Чат открывается официальным виджетом Yandex AI Studio для канала `aacohur22fi0h989vl73`. Данные каталога поступают из бэкенда; локальный демонстрационный каталог больше не используется.

## Запуск

Сначала запустите бэкенд и его PostgreSQL, Redis и MinIO по инструкции в `../parkit-backend/README.md`. Затем из этой папки:

```bash
cp .env.example .env
bun run build
bun run start
```

Откройте `http://localhost:8765`. В `.env` укажите `API_URL` с префиксом `/api/v1`, например `http://localhost:3000/api/v1`. Адрес встраивается в сайт при сборке, поэтому после его изменения повторите `bun run build`. `FRONTEND_PORT` меняет порт сайта. В проекте нет npm-зависимостей: достаточно установленного Bun.

Для быстрой пересборки и запуска используйте `bun run dev`. Бэкенд разрешает CORS для локального сайта.

## Как пользоваться

1. В «Летописях» загрузите PDF, TXT или Markdown до 50 МБ. Статус очереди обновляется через HTTP long polling; открытая страница получает результат без перезагрузки.
2. В «Наблюдениях» ищите по словам или включите строгие фильтры. Фильтры сравнивают значения в индексе точно и совместно. Откройте карточку для цитаты и ссылки на страницу исходного файла.
3. Скачайте текущую выборку в CSV или Excel. Ссылка на источник в выгрузке подписана MinIO и имеет ограниченный срок действия.
4. Откройте чат кнопкой Yandex AI Studio в правом нижнем углу. Ответы и оформление Markdown обрабатывает виджет опубликованного агента. Если кнопка не появляется, проверьте разрешённые домены канала в AI Studio; для локальной проверки нужен `localhost`.
5. В «Проверке» можно отдельно вызвать OCR, извлечение наблюдений LLM и RAG-поиск. Эти вызовы используют настройки Yandex Cloud бэкенда и могут расходовать квоту.

Для отчёта введите в разделе «Наблюдения» запрос, например «Сравни число наблюдений по видам за 2020 год», нажмите «Найти» и скачайте Excel. Строгие фильтры формы также применяются к отчёту.
